# Enhanced Code Rendering & Generative UI Guide

## Overview

This document describes the enhanced code rendering capabilities and Generative UI features added to LlamaTutor's chat interface. These features provide rich, interactive message rendering with syntax highlighting, code controls, and dynamic UI component support.

## Features Implemented

### 1. Rich Code Block Rendering

Code blocks in markdown are now rendered with enhanced styling and interactive controls.

#### Features:
- **Syntax Highlighting**: Uses Prism.js via `react-syntax-highlighter` with the OneDark theme
- **Language Detection**: Automatically detects code language from fenced code block markers (```language)
- **Copy Button**: Click "Copy" to copy code to clipboard with visual feedback (shows "Copied!" for 2 seconds)
- **Download Button**: Click "Download" to download code as a file with appropriate extension
- **File Extensions**: Automatically maps language to extension (python→py, javascript→js, etc.)
- **Line Wrapping**: Long lines wrap automatically for better readability
- **Responsive Design**: Code blocks adapt to screen size with horizontal scrolling on small screens

#### Supported Languages:
- JavaScript/TypeScript (js/ts)
- Python (py)
- Java (java)
- C/C++/C# (cpp/cs)
- PHP (php)
- Ruby (rb)
- Go (go)
- Rust (rs)
- Swift (swift)
- Kotlin (kt)
- HTML/CSS/SCSS/LESS (html/css/scss/less)
- SQL (sql)
- JSON/XML (json/xml)
- YAML (yaml)
- Bash/Shell/ZSH/Fish (sh/zsh/fish)
- PowerShell (ps1)
- Markdown (md)
- And many more via Prism.js

### 2. Code Block Controls

#### Copy Button
```
Usage: Click the "Copy" button in the code block header
- Copies code to clipboard
- Shows "Copied!" confirmation for 2 seconds
- Returns to "Copy" state when timeout expires
```

#### Download Button
```
Usage: Click the "Download" button in the code block header
- Downloads code as a file
- Filename format: code_<timestamp>.<extension>
- Extension determined by language (python→py, javascript→js, etc.)
- Falls back to .txt for unknown languages
- File opens in download directory
```

#### Language Label
```
Displays the detected language (python, javascript, etc.)
- Shown in the code block header
- Auto-detected from markdown fence marker
- Shows "code" for unmarked code blocks
```

A new `GenerativeUI` component supports rendering rich, interactive UI elements dynamically generated by LLMs.

#### Supported Element Types:

```typescript

  children: "Some rendered text"
}
```

**Button**
```typescript

  type: "button",
  props: {
    label: "Click me",
    variant: "primary" | "secondary" | "danger",
    action: "action_name"
  }
}
```

**Card**
```typescript
{
  type: "card",

    title: "Card Title",
    subtitle: "Card Subtitle",
    variant: "default" | "info" | "success" | "warning" | "error"
  },
  children: "Card content"

**List**
```typescript
{
  type: "list",
  props: {
    items: ["Item 1", "Item 2", "Item 3"],
    ordered: false // true for numbered list
  }

```

**Table**
```typescript

**Code**
```typescript

  type: "code",

    language: "python",

  children: "code content"

### 5. UI/UX Design

#### Code Block Styling
- **Header**: Dark gray (bg-gray-800) with language label and controls
- **Buttons**: Hover effect with color change (gray-700 → gray-600)
- **Icons**: Lucide React icons (Copy, Download, CheckCircle2)
- **Background**: Dark (bg-gray-900) with border (border-gray-700)
- **Text**: Monospace font, OneDark theme colors
- **Padding**: 1rem code, 0.75rem header

#### Responsive Behavior
- **Mobile**: Full width with horizontal scroll for long lines
- **Tablet**: Same as mobile, optimized padding
- **Desktop**: Full width, line wrapping enabled

#### Visual Feedback
- **Copy Button**: Changes to "✓ Copied!" with CheckCircle2 icon for 2 seconds
- **Hover States**: All buttons have hover background color change
- **Transitions**: Smooth color transitions (transition-colors)

### 7. Integration with Chat API

To use Generative UI elements, pass them in message objects:

```typescript
// API Response Format
{
  role: "assistant",
  content: "Here's some explanation...",
  generativeUIElements: [
    { type: "alert", props: { severity: "info" }, children: "Note:" },
    { type: "code", props: { language: "python" }, children: "code here" }
  ]
}
```

### 9. Performance Considerations

- **Lazy Loading**: Code highlighting happens on render
- **Memoization**: Consider useMemo for large code blocks
- **Streaming**: Code updates smoothly as content streams in
- **Re-renders**: Minimal re-renders due to local state management

## Troubleshooting

### Code not highlighting
- Check language identifier in markdown fence (```python, ```js, etc.)
- Ensure Prism.js is loaded
- Check browser console for errors

### Copy not working
- Verify browser supports Clipboard API
- Check permissions in browser settings
- Verify code content isn't empty

### Download file extension incorrect
- Add language to `languageToExtension` map
- Default is .txt if language not recognized
- File naming is code_<timestamp>.<ext>
